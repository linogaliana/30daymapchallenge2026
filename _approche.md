Pour ce *30DayMapChallenge*, je veux montrer l'étendue des questions que l'on peut explorer avec les données de la statistique publique française.

Chaque jour propose au moins une carte construite à partir de données ouvertes diffusées par l'un des 17 organismes du [service statistique public](https://www.insee.fr/fr/information/1302192), ou tirée d'une étude qui s'appuie sur ces données.

Tout le site est reproductible : chaque page part des fichiers diffusés en *open data* et montre le code qui mène jusqu'à la carte. Les traitements sont écrits en Python {{< fa brands python >}}, le plus souvent avec [`DuckDB`](https://duckdb.org/), et les cartes interactives en JavaScript {{< fa brands js-square >}}. 

Pour voir ce que [`DuckDB`](https://duckdb.org/) apporte à un projet de valorisation de données, vous pouvez consulter mon cours [Python pour la data science (pythonds.linogaliana.fr/)](https://pythonds.linogaliana.fr/) ou celui que je donne avec Romain Avouac sur la [mise en production de projets *data science* (ensae-reproductibilite.github.io/)](https://ensae-reproductibilite.github.io/).
